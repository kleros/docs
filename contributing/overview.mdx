# Contributing to Kleros

Kleros is open source. Contributions are welcome across smart contracts, frontends, subgraphs, bots, and documentation.

---

## Repositories

| Repository | Description | Language |
| --- | --- | --- |
| [kleros-v2](https://github.com/kleros/kleros-v2) | Core protocol: contracts, court frontend, SDK, subgraph, bots | TypeScript, Solidity |
| [curate-v2](https://github.com/kleros/curate-v2) | Curate V2 frontend and contracts | TypeScript |
| [escrow-v2](https://github.com/kleros/escrow-v2) | Escrow V2 monorepo | TypeScript |
| [vea](https://github.com/kleros/vea) | Cross-chain message bridge | TypeScript, Solidity |
| [scout](https://github.com/kleros/scout) | Scout frontend | TypeScript |
| [ui-components-library](https://github.com/kleros/ui-components-library) | React components for Kleros apps, published as `@kleros/ui-components-library` | TypeScript |
| [design-system](https://github.com/kleros/design-system) | Kleros design context for AI agents: tokens, guidelines, components and UI kits, packaged as skills | CSS, JSX, Markdown |

Full repository list: [github.com/kleros](https://github.com/kleros)

---

## Frontend and Branding

Building a Kleros interface, page or visual asset? Point your agent to these sources first, so the result follows the Kleros look instead of inventing its own.

| Source | Use it for |
| --- | --- |
| [ui-components-library](https://github.com/kleros/ui-components-library) | App interfaces. React components and light and dark themes, used by Court V2, Escrow V2 and Curate. Install `@kleros/ui-components-library` and follow the setup in its README. |
| [design-system](https://github.com/kleros/design-system) | Design context for AI agents. Each folder is a skill with tokens, guidelines, components and UI kits: `kleros-jb` (brand and website), `kleros-harmeet` (the shipped UI components library), `kleros-ai` (Kleros × AI pages). |
| [Brand assets](https://kleros.io/brand-assets) | Logos, product logos, colors, the Urbanist font, and Kleros badges for projects using Kleros. |

---

## Getting Started

1. Pick a repository and read its README
2. Check open issues labeled `good first issue` or `help wanted`
3. Follow the [development workflow](/contributing/dev-workflow) for branching and PR conventions
4. For smart contract work, follow the [smart contract workflow](/contributing/smart-contract-workflow)
5. Follow the [code style guidelines](/contributing/code-style)
