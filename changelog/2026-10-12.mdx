## New features

### September staking rewards available to claim

September 2026 PNK staking rewards are live in [Kleros Court](/court/overview). Open the claim modal on Ethereum or Gnosis to collect them.

### Verified Reality.eth answer options in Dispute Resolver

[Dispute Resolver](/developers/products/dispute-resolver/overview) now builds the answer options of [Reality.eth](/products/reality) cases from the on-chain question and its template, as Court does. Crafted question parameters can no longer change the options you see.

Dispute Resolver also shows a notice on the case page when:

- Other interfaces display different answer options. Vote according to the options shown in Dispute Resolver.
- The question parameters are malformed, or the options could not be verified or determined. Read the question carefully. If in doubt, refuse to arbitrate.

## Updates

### Only reviewed case scripts run in Court and Dispute Resolver

[Kleros Court](/court/overview) and [Dispute Resolver](/developers/products/dispute-resolver/overview) now only run case display scripts that Kleros has reviewed. This protects your wallet from malicious scripts attached to a case. If a case uses a script that hasn't been reviewed, Court treats its data as invalid and advises you to refuse to arbitrate until the script is reviewed.

## Bug fixes

**Appeal rewards wording in Dispute Resolver** — The appeal funding card no longer shows a misleading "Return of Investment" estimate. It now explains that rewards only apply if both sides are funded and your option wins. If no appeal takes place, your contribution is refunded. See [Appeals](/court/appeals).
