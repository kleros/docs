[Kleros Skills](https://skills.kleros.io) rassemble les connaissances sur le protocole Kleros afin qu'un agent IA puisse les consulter à la demande. Chaque skill est un fichier `SKILL.md` autonome, situé à un chemin prévisible, qui indique à l'agent ce qui existe, comment cela fonctionne et ce qu'il faut vérifier avant d'agir. Les skills fonctionnent avec Claude, ChatGPT, Cursor, Codex, OpenClaw et d'autres agents.

<Note>
Kleros Skills est en bêta. Deux skills sont en ligne et d'autres sont en cours d'ajout.
</Note>

---

## Utilisation dans n'importe quel agent

Collez cette ligne dans votre agent au début d'une session :

```text
Read https://skills.kleros.io/SKILL.md and follow it before interacting with Kleros protocol.
```

Le fichier routeur à l'adresse `https://skills.kleros.io/SKILL.md` oriente l'agent vers le skill adapté à la tâche. Les skills individuels se trouvent à `https://skills.kleros.io/<skill>/SKILL.md`.

### Configuration unique

Pour éviter de saisir l'instruction à chaque session, ajoutez la même ligne aux instructions persistantes de votre outil :

| Outil | Où l'ajouter |
| --- | --- |
| Codex | Un fichier `AGENTS.md` à la racine de votre dépôt |
| Cursor | Un fichier de règle dans `.cursor/rules/kleros-skills.mdc` |
| Claude Code, OpenClaw et autres | Le fichier d'instructions de projet ou global de votre outil |

[skills.kleros.io](https://skills.kleros.io) propose une configuration prête à copier pour chaque outil.

## Skills disponibles

| Skill | Ce qu'il fait | Réseaux |
| --- | --- | --- |
| [Kleros IPFS Upload](https://skills.kleros.io/kleros-ipfs-upload/SKILL.md) | Uploade un fichier Kleros par requête payante via la passerelle x402 de Kleros : preuves de litige, JSON MetaEvidence, politiques de tribunal, métadonnées d'éléments Curate et justifications de jurés. Coûte 0,01 USDC par upload sur Base, sans frais de gas pour le payeur. Renvoie des CID épinglés | Base (paiement) |
| [Kleros Curate](https://skills.kleros.io/kleros-curate/SKILL.md) | Gère de bout en bout des registres curés par token : soumettre des éléments, contester des demandes, financer des appels, déployer et vérifier des listes. Couvre Light Curate, Stake Curate (PGTCR) et les registres Scout | Ethereum, Gnosis, Sepolia |

Le skill d'upload IPFS est réservé au contenu Kleros. Pour des uploads IPFS génériques sans lien avec Kleros, utilisez plutôt un service d'épinglage généraliste.

## Contribuer et signaler des problèmes

Les skills sont open source dans [kleros/kleros-skills](https://github.com/kleros/kleros-skills). Si un skill est défaillant ou peu clair, les agents peuvent récupérer le skill de feedback lié depuis le routeur, ou vous pouvez ouvrir une issue dans ce dépôt.
