---
title: "Serveur MCP"
description: "Interrogez la documentation Kleros directement depuis Claude, Cursor, Copilot et d'autres assistants IA compatibles MCP pour obtenir un contexte d'intégration précis et à jour."
---

Le site de documentation Kleros expose un **serveur MCP (Model Context Protocol)** qui permet aux assistants de code IA - Claude, Cursor, VS Code Copilot et d'autres - d'interroger directement cette documentation comme contexte lorsque vous développez une intégration Kleros.

Votre assistant IA peut ainsi répondre à des questions comme « quel est l'encodage correct de extraData pour V2 ? » ou « montre-moi l'interface IArbitrableV2 » en lisant la documentation de référence plutôt qu'en s'appuyant sur des données d'entraînement potentiellement obsolètes.

---

## URL du serveur MCP

```
https://docs.kleros.io/mcp
```

Le serveur MCP expose l'intégralité du contenu de la documentation Kleros dans un format que les clients MCP peuvent interroger en langage naturel.

---

## Instructions de configuration

<Tabs>
  <Tab title="Claude Code">
    Exécutez cette commande depuis n'importe quel répertoire (installation globale) :

    ```bash
    claude mcp add kleros-docs --transport http https://docs.kleros.io/mcp
    ```

    Ou ajoutez-le manuellement à `~/.claude/settings.json` :

    ```json
    {
      "mcpServers": {
        "kleros-docs": {
          "type": "http",
          "url": "https://docs.kleros.io/mcp"
        }
      }
    }
    ```

    Une fois connecté, Claude Code peut répondre aux questions d'intégration Kleros directement pendant que vous codez.
  </Tab>

  <Tab title="Claude Desktop">
    Ajoutez à `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) ou `%APPDATA%\Claude\claude_desktop_config.json` (Windows) :

    ```json
    {
      "mcpServers": {
        "kleros-docs": {
          "type": "http",
          "url": "https://docs.kleros.io/mcp"
        }
      }
    }
    ```

    Redémarrez Claude Desktop après l'enregistrement.
  </Tab>

  <Tab title="Cursor">
    Ouvrez **Settings → MCP → Add Server** et saisissez :

    - **Name :** `kleros-docs`
    - **URL :** `https://docs.kleros.io/mcp`
    - **Transport :** HTTP

    Ou ajoutez à `.cursor/mcp.json` dans votre projet :

    ```json
    {
      "mcpServers": {
        "kleros-docs": {
          "type": "http",
          "url": "https://docs.kleros.io/mcp"
        }
      }
    }
    ```
  </Tab>

  <Tab title="VS Code">
    Ajoutez à votre `.vscode/settings.json` ou à vos paramètres utilisateur :

    ```json
    {
      "github.copilot.chat.mcp.servers": {
        "kleros-docs": {
          "type": "http",
          "url": "https://docs.kleros.io/mcp"
        }
      }
    }
    ```
  </Tab>

  <Tab title="Windsurf">
    Ajoutez à `~/.codeium/windsurf/mcp_config.json` :

    ```json
    {
      "mcpServers": {
        "kleros-docs": {
          "type": "http",
          "url": "https://docs.kleros.io/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Ce que vous pouvez demander

Une fois connecté, votre assistant IA a accès à l'intégralité de la documentation Kleros. Quelques prompts utiles pour développer des intégrations :

```
What is the correct extraData encoding for Kleros V2?
Show me the IArbitrableV2 interface.
How do I register a dispute template?
What are the data mapping types for dispute templates?
How do I handle ruling 0 (refuse to arbitrate)?
What are the KlerosCore contract addresses on Arbitrum One?
How do I integrate Curate V2 into my contract?
What subgraph queries can I use to fetch dispute data?
How do I set up cross-chain arbitration with Vea?
```

## Endpoints adaptés aux LLM

En plus du serveur MCP, le site de documentation expose deux endpoints sous forme de fichiers plats destinés aux LLM :

| Endpoint | Description |
|----------|-------------|
| `https://docs.kleros.io/llms.txt` | Index de toutes les pages avec leurs titres et descriptions |
| `https://docs.kleros.io/llms-full.txt` | Contenu textuel complet de toutes les pages, concaténé |

Ils sont utiles pour charger le contexte en une seule fois dans les systèmes qui ne prennent pas en charge MCP, comme les pipelines LLM personnalisés ou les systèmes RAG.

---

## IA contextuelle sur chaque page

Chaque page de la documentation comporte un bouton d'IA contextuelle dans le coin supérieur droit. Cliquez sur le bouton **Ask AI** (ou utilisez le raccourci clavier correspondant) pour ouvrir un chat qui a la page actuelle comme contexte.

L'IA au niveau de la page comprend la section précise que vous lisez et peut répondre à des questions complémentaires sans que vous ayez à copier-coller du contenu.

---

<Note>
Le contenu du serveur MCP est reconstruit à chaque déploiement de la documentation. Vous obtenez toujours la dernière version de la documentation, y compris les adresses de contrats, changements d'API et modèles d'intégration les plus récents.
</Note>

<Tip>
Si l'IA vous donne des réponses obsolètes (par exemple, de mauvaises adresses de contrats ou des modèles dépréciés comme `arbitrumGoerliToChiadoDevnet`), la cause la plus probable est qu'elle répond à partir de ses données d'entraînement plutôt que du serveur MCP. Vérifiez que le MCP est connecté et demandez à l'IA de revérifier à l'aide de la documentation.
</Tip>
