description: 'Todo sitio de Mintlify se configura mediante docs.json. Revisa las propiedades principales que controlan el tema, los colores, el logo, la navegación y el aspecto general.'

Todo sitio de Mintlify necesita un archivo `docs.json` con los ajustes de configuración principales. Obtén más información sobre las [propiedades](#propiedades) a continuación.

## Propiedades

<ResponseField name="name" type="string" required>
Nombre de tu proyecto. Se usa para el título global.

Ejemplo: `mintlify`

</ResponseField>

<ResponseField name="navigation" type="Navigation[]" required>
  Un array de grupos con todas las páginas de ese grupo
  <Expandable title="Navigation">
    <ResponseField name="group" type="string">
    El nombre del grupo.

    Ejemplo: `Settings`

    </ResponseField>
    <ResponseField name="pages" type="string[]">
    Las rutas relativas a los archivos markdown que servirán como páginas.

    Ejemplo: `["customization", "page"]`

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="logo" type="string or object">
  Ruta a la imagen del logo u objeto con la ruta a las imágenes del logo en modo "light" y "dark"
  <Expandable title="Logo">
    <ResponseField name="light" type="string">
      Ruta al logo en modo claro
    </ResponseField>
    <ResponseField name="dark" type="string">
      Ruta al logo en modo oscuro
    </ResponseField>
    <ResponseField name="href" type="string" default="/">
      A dónde te lleva hacer clic en el logo
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="favicon" type="string">
  Ruta a la imagen del favicon
</ResponseField>

<ResponseField name="colors" type="Colors">
  Códigos de color hexadecimales para tu tema global
  <Expandable title="Colors">
    <ResponseField name="primary" type="string" required>
      El color primario. Se usa con mayor frecuencia para contenido destacado,
      encabezados de sección y acentos, en modo claro
    </ResponseField>
    <ResponseField name="light" type="string">
      El color primario para el modo oscuro. Se usa con mayor frecuencia para
      contenido destacado, encabezados de sección y acentos, en modo oscuro
    </ResponseField>
    <ResponseField name="dark" type="string">
      El color primario para botones importantes
    </ResponseField>
    <ResponseField name="background" type="object">
      El color del fondo tanto en modo claro como oscuro
      <Expandable title="Objeto">
        <ResponseField name="light" type="string" required>
          El código de color hexadecimal del fondo en modo claro
        </ResponseField>
        <ResponseField name="dark" type="string" required>
          El código de color hexadecimal del fondo en modo oscuro
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topbarLinks" type="TopbarLink[]">
  Array de `name`s y `url`s de los enlaces que quieres incluir en la barra superior
  <Expandable title="TopbarLink">
    <ResponseField name="name" type="string">
    El nombre del botón.

    Ejemplo: `Contact us`
    </ResponseField>
    <ResponseField name="url" type="string">
    La url al hacer clic en el botón. Ejemplo: `https://mintlify.com/docs`
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topbarCtaButton" type="Call to Action">
  <Expandable title="Llamada a la acción de la barra superior">
    <ResponseField name="type" type={'"link" or "github"'} default="link">
    Link muestra un botón. GitHub muestra la información del repositorio en la url proporcionada, incluido el número de estrellas de GitHub.
    </ResponseField>
    <ResponseField name="url" type="string">
    Si es `link`: a dónde enlaza el botón.
    
    Si es `github`: enlace al repositorio del que cargar la información de GitHub.
    </ResponseField>
    <ResponseField name="name" type="string">
    Texto dentro del botón. Solo es obligatorio si `type` es `link`.
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="versions" type="string[]">
  Array de nombres de versiones. Úsalo solo si quieres mostrar diferentes versiones
  de la documentación con un menú desplegable en la barra de navegación.
</ResponseField>

<ResponseField name="anchors" type="Anchor[]">
  Un array de anclas, incluye `icon`, `color` y `url`.
  <Expandable title="Anchor">
    <ResponseField name="icon" type="string">
    El icono de [Font Awesome](https://fontawesome.com/search?q=heart) usado para destacar el ancla.

    Ejemplo: `comments`
    </ResponseField>
    <ResponseField name="name" type="string">
    El nombre de la etiqueta del ancla.

    Ejemplo: `Community`
    </ResponseField>
    <ResponseField name="url" type="string">
      El inicio de la URL que marca qué páginas van en el ancla. Generalmente, es el nombre de la carpeta en la que colocas tus páginas.
    </ResponseField>
    <ResponseField name="color" type="string">
      El color hexadecimal del fondo del icono del ancla. También puede ser un degradado si pasas un objeto con las propiedades `from` y `to`, cada una con un color hexadecimal.
    </ResponseField>
    <ResponseField name="version" type="string">
      Se usa si quieres ocultar un ancla hasta que se seleccione la versión correcta de la documentación.
    </ResponseField>
    <ResponseField name="isDefaultHidden" type="boolean" default="false">
      Pasa `true` si quieres ocultar el ancla hasta que enlaces directamente a alguien a documentación dentro de ella.
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      Uno de: "brands", "duotone", "light", "sharp-solid", "solid" o "thin"
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topAnchor" type="Object">
  Sobrescribe la configuración predeterminada del ancla superior.
  <Expandable title="Objeto">
    <ResponseField name="name" default="Documentation" type="string">
      El nombre del ancla superior
    </ResponseField>
    <ResponseField name="icon" default="book-open" type="string">
      Icono de Font Awesome.
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      Uno de: "brands", "duotone", "light", "sharp-solid", "solid" o "thin"
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tabs" type="Tabs[]">
  Un array de pestañas de navegación.
  <Expandable title="Tabs">
    <ResponseField name="name" type="string">
      El nombre de la etiqueta de la pestaña.
    </ResponseField>
    <ResponseField name="url" type="string">
      El inicio de la URL que marca qué páginas van en la pestaña. Generalmente,
      es el nombre de la carpeta en la que colocas tus páginas.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api" type="API">
  Configuración de los ajustes de la API.
  <Expandable title="API">
    <ResponseField name="baseUrl" type="string">
      La url base para todos los endpoints de la API. Si `baseUrl` es un array, habilitará múltiples opciones de url base
      que el usuario puede alternar.
    </ResponseField>

    <ResponseField name="auth" type="Auth">
      <Expandable title="Auth">
        <ResponseField name="method" type='"bearer" | "basic" | "key"'>
          La estrategia de autenticación usada para todos los endpoints de la API.
        </ResponseField>
        <ResponseField name="name" type="string">
        El nombre del parámetro de autenticación usado en el playground de la API.

        Si el método es `basic`, el formato debe ser `[usernameName]:[passwordName]`
        </ResponseField>
        <ResponseField name="inputPrefix" type="string">
        El valor predeterminado diseñado para ser un prefijo del campo de entrada de autenticación.

        Por ejemplo, un `inputPrefix` de `AuthKey` heredaría el resultado de entrada predeterminado del campo de autenticación como `AuthKey`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="playground" type="Playground">
      Configuraciones del playground de la API

      <Expandable title="Playground">
        <ResponseField name="mode" default="show" type='"show" | "simple" | "hide"'>
          Si el playground se muestra, se oculta o solo muestra el endpoint sin interactividad adicional para el usuario `simple`

          Obtén más información en las guías del playground
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="maintainOrder" type="boolean">
      Activar esta opción garantiza que el orden de las claves en las páginas OpenAPI coincida con el orden de claves definido en el archivo OpenAPI.

      <Warning>Este comportamiento pronto estará habilitado por defecto, momento en el que este campo quedará obsoleto.</Warning>
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="openapi" type="string | string[]">
  Una cadena o un array de cadenas de URL(s) o ruta(s) relativa(s) que apuntan a tu
  archivo OpenAPI.
  
  Ejemplos:
  <CodeGroup>
    ```json Absolute
    "openapi": "https://example.com/openapi.json"
    ```
    ```json Relative
    "openapi": "/openapi.json"
    ```
    ```json Multiple
    "openapi": ["https://example.com/openapi1.json", "/openapi2.json", "/openapi3.json"]
    ```
  </CodeGroup>

</ResponseField>

<ResponseField name="footerSocials" type="FooterSocials">
  Un objeto de cuentas de redes sociales donde el par clave:propiedad representa la plataforma de red social y la url de la cuenta.
  
  Ejemplo: 
  ```json
  {
    "x": "https://x.com/mintlify",
    "website": "https://mintlify.com"
  }
  ```
  <Expandable title="FooterSocials">
    <ResponseField name="[key]" type="string">
    Uno de los siguientes valores: `website`, `facebook`, `x`, `discord`, `slack`, `github`, `linkedin`, `instagram`, `hacker-news`
    
    Ejemplo: `x`
    </ResponseField>
    <ResponseField name="property" type="string">
    La URL de la plataforma social.
    
    Ejemplo: `https://x.com/mintlify`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="feedback" type="Feedback">
  Configuraciones para habilitar los botones de comentarios

  <Expandable title="Feedback">
    <ResponseField name="suggestEdit" type="boolean" default="false">
    Habilita un botón que permite a los usuarios sugerir ediciones mediante pull requests
    </ResponseField>
    <ResponseField name="raiseIssue" type="boolean" default="false">
    Habilita un botón que permite a los usuarios abrir un issue sobre la documentación
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="modeToggle" type="ModeToggle">
  Personaliza el selector de modo oscuro.
  <Expandable title="ModeToggle">
    <ResponseField name="default" type={'"light" or "dark"'}>
      Configúralo si quieres mostrar siempre el modo claro u oscuro a los usuarios nuevos. Si no
      se configura, usamos por defecto el mismo modo que el sistema operativo del usuario.
    </ResponseField>
    <ResponseField name="isHidden" type="boolean" default="false">
      Configúralo en true para ocultar el selector de modo oscuro/claro. Puedes combinar `isHidden` con `default` para forzar que tu documentación use solo el modo claro u oscuro. Por ejemplo:
      
      <CodeGroup>
      ```json Only Dark Mode
      "modeToggle": {
        "default": "dark",
        "isHidden": true
      }
      ```

      ```json Only Light Mode
      "modeToggle": {
        "default": "light",
        "isHidden": true
      }
      ```
      </CodeGroup>

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="backgroundImage" type="string">
  Una imagen de fondo que se mostrará detrás de cada página. Consulta el ejemplo con
  [Infisical](https://infisical.com/docs) y [FRPC](https://frpc.io).
</ResponseField>
