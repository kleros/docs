## Descripción general

Esta sección documenta todos los productos de Kleros, con V1 y V2 cubiertos conjuntamente en la página de cada producto.

**Los productos V1 incluyen guías de integración completas y ejemplos de código. Los productos V2 documentan especificaciones técnicas, interfaces de contratos y arquitectura.**

Todos los productos usan Kleros Court como backend de arbitraje. Las disputas iniciadas a través de cualquier producto siguen el mismo flujo de resolución: sorteo de jurados, envío de pruebas, votación, apelación y ejecución del fallo.

## Infraestructura compartida

Todos los productos de Kleros V2 comparten estos componentes:

| Componente | Función |
| --- | --- |
| **KlerosCore** | Contrato árbitro central en Arbitrum One |
| **SortitionModule** | Selección aleatoria de jurados ponderada por stake |
| **DisputeKitClassic** | Lógica predeterminada de votación y apelación |
| **DisputeTemplateRegistry** | Almacena los metadatos de visualización de disputas para la interfaz de Court |
| **Vea** | Puente de mensajes cross-chain para retransmitir disputas y fallos |

Para la arquitectura completa, consulta la [guía de arquitectura](/es/developers/architecture).
