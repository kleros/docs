## Descripción general {#overview}

Esta sección documenta todos los productos de Kleros, con V1 y V2 tratados juntos en la página de cada producto.

**Los productos V1 incluyen guías de integración completas y ejemplos de código. Los productos V2 documentan las especificaciones técnicas, las interfaces de los contratos y la arquitectura.**

Todos los productos usan Kleros Court como backend de arbitraje. Las disputas que se abren mediante cualquier producto siguen el mismo flujo de resolución: sorteo de jurados, presentación de evidencias, votación, apelación y ejecución del fallo.

## Infraestructura compartida {#shared-infrastructure}

Todos los productos de Kleros V2 comparten estos componentes:

| Componente | Función |
| --- | --- |
| **KlerosCore** | Contrato árbitro central en Arbitrum One |
| **SortitionModule** | Selección aleatoria de jurados ponderada por stake |
| **DisputeKitClassic** | Lógica predeterminada de votación y apelación |
| **DisputeTemplateRegistry** | Almacena los metadatos de visualización de las disputas para la interfaz de Court |
| **Vea** | Puente de mensajes entre cadenas para transmitir disputas y fallos |

Para ver la arquitectura completa, consulta la [guía de arquitectura](/es/developers/architecture).
