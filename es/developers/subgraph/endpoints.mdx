title: "Endpoints del subgraph"
description: "Endpoints GraphQL de los subgraphs core y DRT de Kleros V2 y de los subgraphs de V1 en Arbitrum, Ethereum y Gnosis, servidos mediante la red descentralizada de The Graph y Goldsky."
---



Todos los subgraphs de Kleros están desplegados en The Graph. Usa estos endpoints para consultar los datos de Kleros mediante GraphQL.

Todos los subgraphs que Kleros publica en la red descentralizada de The Graph aparecen en el [perfil del desplegador de Kleros en Graph Explorer](https://thegraph.com/explorer/profile/0x7f3a845bf7aa9eb6da3dc53518ff22a2f65612e6?chain=arbitrum-one&view=Subgraphs). Cada página de Explorer muestra el ID del subgraph y la URL de consulta exacta.

<Note>
**Infraestructura:** los subgraphs se migraron de Alchemy a Goldsky tras el cierre del servicio de subgraphs de Alchemy (de diciembre de 2025 a enero de 2026). El subgraph core 0.18.1 y el subgraph DRT 0.14.0 se desplegaron en Goldsky (noviembre de 2025), y el GTCR Indexer llegó a la v0.1.7 con una rama de Envio (abril de 2026). Algunas aplicaciones usan Envio HyperIndex como indexador principal, con un subgraph como respaldo.
</Note>

<Warning>
Los endpoints de los subgraphs en la red descentralizada requieren una **clave de API de The Graph**. Consíguela en [thegraph.com/studio](https://thegraph.com/studio). En las asignaciones de las plantillas verás `{{{graphApiKey}}}`: el Kleros SDK la inyecta en tiempo de ejecución.
</Warning>

## Consultar los subgraphs {#querying-subgraphs}

Todos los subgraphs exponen una API GraphQL. Consúltalos con cualquier cliente GraphQL:





```typescript
const SUBGRAPH_URL =
  `https://gateway.thegraph.com/api/${process.env.GRAPH_API_KEY}/subgraphs/id/96vpnRJbRVkzF6usMNYMMoziSZEfSwGEDpXNi2h9WBSW`;

const response = await fetch(SUBGRAPH_URL, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    query: `{
      courts(first: 10) {
        id
        policy { policy }
        minStake
        timesPerPeriod
      }
    }`
  })
});

const { data } = await response.json();
```

<Note>
Las direcciones de las respuestas de los subgraphs están siempre en **hexadecimal en minúsculas** (sin checksum EIP-55). Pon siempre en minúsculas las direcciones de las variables de tus consultas o el subgraph no devolverá resultados.
</Note>
