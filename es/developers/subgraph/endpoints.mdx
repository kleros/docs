---



Todos los subgraphs de Kleros están desplegados en The Graph. Usa estos endpoints para consultar datos de Kleros mediante GraphQL.

Todos los subgraphs publicados por Kleros en la red descentralizada de The Graph aparecen en el [perfil de despliegue de Kleros en Graph Explorer](https://thegraph.com/explorer/profile/0x7f3a845bf7aa9eb6da3dc53518ff22a2f65612e6?chain=arbitrum-one&view=Subgraphs). Cada página de Explorer muestra el ID del subgraph y la URL de consulta exacta.

<Note>
**Infraestructura:** los subgraphs se migraron de Alchemy a Goldsky tras el cierre del servicio de subgraphs de Alchemy (diciembre de 2025–enero de 2026). El subgraph core 0.18.1 y el subgraph DRT 0.14.0 se desplegaron en Goldsky (noviembre de 2025), y el GTCR Indexer alcanzó la v0.1.7 con una rama de Envio (abril de 2026). Algunas aplicaciones usan Envio HyperIndex como indexador principal y un subgraph como respaldo.
</Note>

<Warning>
Los endpoints de subgraphs en la red descentralizada requieren una **clave de API de Graph**. Obtén una en [thegraph.com/studio](https://thegraph.com/studio). En los mapeos de plantillas verás `{{{graphApiKey}}}`: el Kleros SDK lo inyecta en tiempo de ejecución.
</Warning>

## Consultar subgraphs

Todos los subgraphs exponen una API GraphQL. Consúltalos con cualquier cliente GraphQL:





```typescript
const SUBGRAPH_URL =
  `https://gateway.thegraph.com/api/${process.env.GRAPH_API_KEY}/subgraphs/id/96vpnRJbRVkzF6usMNYMMoziSZEfSwGEDpXNi2h9WBSW`;

const response = await fetch(SUBGRAPH_URL, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    query: `{
      courts(first: 10) {
        id
        policy { policy }
        minStake
        timesPerPeriod
      }
    }`
  })
});

const { data } = await response.json();
```

<Note>
Las direcciones en las respuestas de los subgraphs siempre están en **hexadecimal en minúsculas** (sin checksum EIP-55). Escribe siempre en minúsculas las direcciones en las variables de tus consultas, o el subgraph no devolverá resultados.
</Note>
