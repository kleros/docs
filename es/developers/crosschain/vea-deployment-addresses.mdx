Las direcciones de las rutas de VeaShi se publican en el paquete `@kleros/veashi-sdk` de npm (v0.1.0 en el momento de redactar esta página). Usa el SDK como fuente de referencia para ellas.

## Despliegues en testnet (Arbitrum Sepolia) {#testnet-deployments-arbitrum-sepolia}

La testnet de Vea funciona en **Arbitrum Sepolia → Chiado (testnet de Gnosis)** y **Arbitrum Sepolia → Ethereum Sepolia**. Sustituyen a las devnets obsoletas basadas en Goerli.

<Note>
Los despliegues basados en Goerli (Arbitrum Goerli → Chiado, Arbitrum Goerli → Goerli) están **obsoletos**, ya que Goerli se retiró en septiembre de 2024. Migra a sus equivalentes en Sepolia.
</Note>

**Dirección del operador de testnet:** `0x407DDEC61d69b212498B140a26da70AE1C879f5a`

## Despliegues en mainnet {#mainnet-deployments}

<Info>
Los despliegues de Vea en mainnet (Arbitrum One → red principal de Ethereum, Arbitrum One → Gnosis Chain) están actualmente en proceso de finalización. El sistema de arbitraje entre cadenas de Kleros V2 usa foreign gateways que se comunican mediante Vea.
</Info>

Para obtener las direcciones de mainnet más recientes cuando estén activas:
- Consulta los artefactos de despliegue del [repositorio de Vea en GitHub](https://github.com/kleros/vea)
- Consulta las [direcciones de despliegue de Kleros V2](/es/reference/contracts/deployment-addresses) para ver las direcciones de los Foreign Gateways que usan Vea

## Obtener las direcciones de forma programática {#finding-addresses-programmatically}

Clona el repositorio de Vea para inspeccionar los artefactos de despliegue:

```bash
git clone https://github.com/kleros/vea.git
cd vea/contracts
# Per-chain deployment JSONs are in deployments/<networkName>/
ls deployments/
```

Cada JSON de despliegue (por ejemplo, `VeaInboxArbToEth.json`) contiene el campo `address` con la dirección del contrato desplegado y la ABI.
