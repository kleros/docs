# Contribuir a Kleros {#contributing-to-kleros}

Kleros es de código abierto. Las contribuciones son bienvenidas en contratos inteligentes, frontends, subgraphs, bots y documentación.

---

## Repositorios {#repositories}

| Repositorio | Descripción | Lenguaje |
| --- | --- | --- |
| [kleros-v2](https://github.com/kleros/kleros-v2) | Protocolo principal: contratos, frontend de Court, SDK, subgraph, bots | TypeScript, Solidity |
| [curate-v2](https://github.com/kleros/curate-v2) | Frontend y contratos de Curate V2 | TypeScript |
| [escrow-v2](https://github.com/kleros/escrow-v2) | Monorepo de Escrow V2 | TypeScript |
| [vea](https://github.com/kleros/vea) | Puente de mensajes entre cadenas | TypeScript, Solidity |
| [scout](https://github.com/kleros/scout) | Frontend de Scout | TypeScript |
| [ui-components-library](https://github.com/kleros/ui-components-library) | Componentes de React para las apps de Kleros, publicados como `@kleros/ui-components-library` | TypeScript |
| [design-system](https://github.com/kleros/design-system) | Contexto de diseño de Kleros para agentes de IA: tokens, pautas, componentes y kits de UI, empaquetados como skills | CSS, JSX, Markdown |

Lista completa de repositorios: [github.com/kleros](https://github.com/kleros)

## Frontend y marca {#frontend-and-branding}

¿Vas a crear una interfaz, una página o un recurso visual de Kleros? Indica primero a tu agente estas fuentes, para que el resultado siga el estilo de Kleros en lugar de inventar uno propio.

| Fuente | Úsala para |
| --- | --- |
| [ui-components-library](https://github.com/kleros/ui-components-library) | Interfaces de apps. Componentes de React y temas claro y oscuro, usados por Court V2, Escrow V2 y Curate. Instala `@kleros/ui-components-library` y sigue la configuración de su README. |
| [design-system](https://github.com/kleros/design-system) | Contexto de diseño para agentes de IA. Cada carpeta es una skill con tokens, pautas, componentes y kits de UI: `kleros-jb` (marca y sitio web), `kleros-harmeet` (la biblioteca de componentes de UI publicada), `kleros-ai` (páginas de Kleros × IA). |
| [Recursos de marca](https://kleros.io/brand-assets) | Logotipos, logotipos de productos, colores, la fuente Urbanist e insignias de Kleros para proyectos que usan Kleros. |

## Primeros pasos {#getting-started}

1. Elige un repositorio y lee su README
2. Consulta los issues abiertos con las etiquetas `good first issue` o `help wanted`
3. Sigue el [flujo de desarrollo](/es/contributing/dev-workflow) para las convenciones de ramas y PR
4. Para el trabajo con contratos inteligentes, sigue el [flujo de contratos inteligentes](/es/contributing/smart-contract-workflow)
5. Sigue las [pautas de estilo de código](/es/contributing/code-style)
