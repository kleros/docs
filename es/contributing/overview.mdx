# Contribuir a Kleros {#contributing-to-kleros}

Kleros es de código abierto. Las contribuciones son bienvenidas en contratos inteligentes, frontends, subgraphs, bots y documentación.

---

## Repositorios {#repositories}

| Repositorio | Descripción | Lenguaje |
| --- | --- | --- |
| [kleros-v2](https://github.com/kleros/kleros-v2) | Protocolo principal: contratos, frontend de Court, SDK, subgraph, bots | TypeScript, Solidity |
| [curate-v2](https://github.com/kleros/curate-v2) | Frontend y contratos de Curate V2 | TypeScript |
| [escrow-v2](https://github.com/kleros/escrow-v2) | Monorepo de Escrow V2 | TypeScript |
| [vea](https://github.com/kleros/vea) | Puente de mensajes entre cadenas | TypeScript, Solidity |
| [scout](https://github.com/kleros/scout) | Frontend de Scout | TypeScript |

Lista completa de repositorios: [github.com/kleros](https://github.com/kleros)

---

## Primeros pasos {#getting-started}

1. Elige un repositorio y lee su README
2. Consulta los issues abiertos con las etiquetas `good first issue` o `help wanted`
3. Sigue el [flujo de desarrollo](/es/contributing/dev-workflow) para las convenciones de ramas y PR
4. Para el trabajo con contratos inteligentes, sigue el [flujo de contratos inteligentes](/es/contributing/smart-contract-workflow)
5. Sigue las [pautas de estilo de código](/es/contributing/code-style)
