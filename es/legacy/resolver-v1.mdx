# Resolver V1 {#resolver-v1}

<Note>
Dispute Resolver V1 es una aplicación independiente en [resolve.kleros.io](https://resolve.kleros.io) que funciona con Kleros Court V1. En V2 no hay una aplicación aparte: la creación de disputas está integrada en la interfaz de [Court V2](/es/court/overview).
</Note>

Kleros Dispute Resolver V1 (antes conocido como "Resolve") es una aplicación web independiente que permite a los usuarios crear disputas arbitrarias en Kleros Court V1 sin construir un contrato arbitrable personalizado. Los usuarios definen la pregunta, las opciones y las evidencias de la disputa y, después, la envían directamente a Court para su resolución.

---

## Qué hace {#what-it-does}

- Permite a cualquiera crear una disputa desde una interfaz web
- No requiere desarrollar contratos inteligentes
- Se usa para desacuerdos sencillos entre dos partes
- Presentación de evidencias y gestión de las apelaciones desde la interfaz del Resolver
- Crea las disputas mediante el [ArbitrableProxy](/es/developers/arbitrable-apps/arbitrable-proxy) de V1 en las cadenas en las que está desplegado Court V1 (consulta las [redes compatibles](/es/developers/products/dispute-resolver/overview#supported-networks))

---

## Estado actual {#current-status}

Dispute Resolver V1 sigue disponible en [resolve.kleros.io](https://resolve.kleros.io) para las disputas de Court V1.

En V2 no hay una aplicación Resolver separada. Los usuarios crean las disputas y presentan las evidencias directamente en la interfaz de [Court V2](/es/court/overview), respaldada por el contrato `DisputeResolver` de V2.
