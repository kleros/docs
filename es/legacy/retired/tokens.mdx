# Tokens (retirado) {#tokens-retired}

<Warning>
La interfaz Tokens se ha retirado. La funcionalidad del registro de tokens forma parte ahora de [Curate](/es/products/curate).
</Warning>

**Kleros Tokens** (también conocido como Token² Curated Registry o T2CR) era una interfaz web independiente para enviar tokens al Kleros Token Registry. Permitía a cualquiera enviar la información de un token (nombre, ticker, dirección, logotipo) para su curación por la comunidad, y los envíos incorrectos podían impugnarse a través de Kleros Court.

---

## Sustituto actual {#current-replacement}

La funcionalidad del registro de tokens se encuentra ahora en [Kleros Curate](/es/products/curate), que ofrece un marco más flexible y de uso general para crear cualquier tipo de registro curado, incluidas listas de tokens, etiquetas de direcciones y más. Los datos de tokens curados mediante Curate se muestran en [Kleros Scout](/es/products/scout).
