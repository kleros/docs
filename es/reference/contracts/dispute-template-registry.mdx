---



Almacena las plantillas de disputa que definen la pregunta, las opciones de respuesta y los metadatos que se presentan a los jurados. Las plantillas se referencian por ID al crear disputas.

## Métodos

### `setDisputeTemplate(string _templateTag, string _templateData, string _templateDataMappings) → uint256`
Registra una nueva plantilla de disputa. Devuelve el ID de la plantilla.

- `_templateTag`  Etiqueta opcional para la categorización
- `_templateData`  Cadena JSON de la plantilla (consulta el [formato de plantilla de disputa](/es/reference/data-formats/dispute-templates))
- `_templateDataMappings`  Mapeo JSON para poblar datos dinámicos

## Eventos

| Evento | Descripción |
|---|---|
| `DisputeTemplate(templateId, templateTag, templateData, templateDataMappings)` | Nueva plantilla registrada |
