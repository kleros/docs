## Nuevas funciones

### Detección de duplicados para Address Tags Queries

[Scout](/es/products/scout) ahora marca los envíos duplicados de Address Tags Queries (ATQ) antes de que firmes. Si ya existe en el registro una entrada con el mismo repositorio de GitHub, hash de commit e ID de cadena EVM, verás un error claro para que puedas revisar el envío existente en lugar de crear un duplicado.

### Enrutamiento a la JavaScript Court

Las disputas relacionadas con envíos de JavaScript en [Scout](/es/products/scout) ahora se dirigen a la JavaScript Court dedicada, de modo que el grupo adecuado de jurados revise cada caso.

## Actualizaciones

### Ciclo de vida de los elementos más claro en Curate

Los registros permanentes de [Curate](/es/products/curate) ahora distinguen los elementos que su remitente **retiró** voluntariamente de los elementos que fueron **eliminados o rechazados** mediante una impugnación. La cronología del elemento muestra cuándo se inició el retiro y cuándo se completó, lo que facilita auditar el historial de cada entrada.

## Corrección de errores

**Billetera Rabby en mainnet**: [Kleros Court](/es/court/overview) ya no falla al conectarse con Rabby (u otras billeteras que no exponen la llamada heredada de ID de cadena) en mainnet. Los enlaces de los contratos ahora se resuelven de forma fiable en todos los proveedores.

**Icono de la ventana emergente de éxito en Foresight**: el icono de confirmación que se muestra después de enviar predicciones en [Foresight](/es/products/foresight) ahora se renderiza con el tamaño correcto.
