[Kleros Skills](https://skills.kleros.io) empaqueta el conocimiento del protocolo Kleros para que un agente de IA pueda leerlo cuando lo necesite. Cada skill es un archivo `SKILL.md` autónomo en una ruta predecible que indica al agente qué existe, cómo funciona y qué debe comprobar antes de actuar. Las skills funcionan con Claude, ChatGPT, Cursor, Codex, OpenClaw y otros agentes.

<Note>
Kleros Skills está en beta. Hay dos skills activas y se están añadiendo más.
</Note>

---

## Úsalo en cualquier agente {#use-it-in-any-agent}

Pega esta línea en tu agente al inicio de una sesión:

```text
Read https://skills.kleros.io/SKILL.md and follow it before interacting with Kleros protocol.
```

El archivo enrutador en `https://skills.kleros.io/SKILL.md` dirige al agente a la skill adecuada para la tarea. Cada skill se encuentra en `https://skills.kleros.io/<skill>/SKILL.md`.

### Configúralo una sola vez {#set-it-up-once}

Para no tener que pegarlo en cada sesión, añade la misma línea a las instrucciones persistentes de tu herramienta:

| Herramienta | Dónde añadirla |
| --- | --- |
| Codex | Un archivo `AGENTS.md` en la raíz de tu repositorio |
| Cursor | Un archivo de reglas en `.cursor/rules/kleros-skills.mdc` |
| Claude Code, OpenClaw y otras | El archivo de instrucciones del proyecto o global de tu herramienta |

[skills.kleros.io](https://skills.kleros.io) tiene una configuración lista para copiar para cada herramienta.

## Skills disponibles {#available-skills}

| Skill | Qué hace | Redes |
| --- | --- | --- |
| [Kleros IPFS Upload](https://skills.kleros.io/kleros-ipfs-upload/SKILL.md) | Sube un archivo de Kleros por cada solicitud pagada a través del gateway x402 de Kleros: evidencias de disputas, JSON de MetaEvidence, políticas de tribunales, metadatos de elementos de Curate y justificaciones de jurados. Cuesta 0,01 USDC por subida en Base, sin gas para quien paga. Devuelve CID fijados | Base (pago) |
| [Kleros Curate](https://skills.kleros.io/kleros-curate/SKILL.md) | Opera registros curados mediante tokens de principio a fin: envía elementos, impugna solicitudes, financia apelaciones y despliega y verifica listas. Cubre Light Curate, Stake Curate (PGTCR) y los registros de Scout | Ethereum, Gnosis, Sepolia |

La skill de subida a IPFS es solo para contenido de Kleros. Para subidas genéricas a IPFS sin contexto de Kleros, usa un servicio de pinning general.

## Contribuye y notifica problemas {#contribute-and-report-issues}

Las skills son de código abierto en [kleros/kleros-skills](https://github.com/kleros/kleros-skills). Si una skill no funciona o resulta confusa, los agentes pueden obtener la skill de comentarios enlazada desde el enrutador, o puedes abrir un issue en ese repositorio.
