title: "Kleros CLI (AgentKit)"
description: "Consulta cortes, disputas, evidencia, políticas y jurados de Kleros desde la terminal o como servidor MCP para agentes de IA, con la CLI @kleros/agentkit."
---

`@kleros/agentkit` es una herramienta de línea de comandos y un servidor MCP para leer datos de Kleros. Tanto los agentes de IA como las personas pueden usarla. Una sola interfaz cubre cortes, disputas, evidencia, políticas de cortes y de disputas, y stakes de jurados en Kleros V1 y V2.

<Note>
**Versión actual: v0.3.0 (septiembre de 2026).** La CLI es de solo lectura y anterior a la 1.0, por lo que sus comandos pueden cambiar entre versiones menores. Las operaciones de escritura (staking, votación, creación de disputas, envío de evidencia, apelaciones) aún no están disponibles.
</Note>

---

## Qué puede hacer

- Explorar cortes, disputas y la actividad de los jurados
- Resolver la política de la corte y de la disputa: las reglas que se pide aplicar a los jurados
- Recorrer los envíos de evidencia, incluidos los adjuntos alojados en IPFS
- Clasificar contratos arbitrables y obtener un resumen combinado de la disputa en una sola llamada
- Clasificar a los jurados según el PNK en stake

La salida usa por defecto [TOON](https://github.com/toon-format/toon), un formato compacto que usa menos tokens que JSON. También hay salida en tabla y en JSON. Cada respuesta incluye un bloque `cta` que sugiere el siguiente comando lógico.

## Cadenas compatibles

| Cadena | Versión de Kleros | Slug |
|---|---|---|
| Ethereum | V1 | `ethereum` |
| Gnosis | V1 | `gnosis` |
| Arbitrum One | V2 (beta) | `arbitrum-one` |
| Arbitrum Sepolia | V2 testnet | `arbitrum-sepolia-testnet` |

Un comando de listado ejecutado sin `--chain` se distribuye entre Ethereum, Gnosis y luego Arbitrum One. V1 y V2 no entienden lo mismo por `ruled`, así que cada fila de `dispute list` lleva un marcador `ruledSemantics`. Usa `dispute get` cuando necesites un fallo leído en vivo desde el contrato del árbitro.

<Warning>
**Actualización desde 0.2.x:** v0.3.0 es una versión con cambios incompatibles. El slug simple `arbitrum-sepolia` queda retirado: usa `arbitrum-sepolia-testnet` en su lugar. La variable de entorno correspondiente `KLEROS_RPC_URL_ARBITRUM_SEPOLIA` se renombra con él y falla en silencio si se deja con el nombre antiguo.
</Warning>

## Inicio rápido

Requiere Node.js 22 o posterior. Ejecútala sin instalar:

```bash
npx -y @kleros/agentkit court list --chain ethereum
npx -y @kleros/agentkit dispute get 797 --chain gnosis --format json
```

O instálala globalmente y usa el comando `kleros`:

```bash
npm i -g @kleros/agentkit
kleros court list --chain ethereum
```

Guarda una cadena predeterminada para no tener que pasar `--chain` cada vez:

```bash
kleros config set chain gnosis
```

## Úsala como servidor MCP

Registra la CLI como servidor de herramientas MCP para que los agentes en Claude Code, Cursor y otros clientes MCP puedan invocar consultas de disputas directamente:

```bash
claude mcp add kleros -- npx -y @kleros/agentkit --mcp
```

Si la CLI está instalada globalmente, `kleros mcp add` la registra para Claude Code y Cursor. Los nombres de las herramientas siguen el patrón `group_command`, por ejemplo `dispute_list`, `court_get` y `juror_info`. Pasa un argumento `chain` en cualquier llamada a una herramienta para elegir la cadena de esa llamada.

Para el descubrimiento por parte de agentes, `kleros --llms` imprime un manifiesto compacto de comandos y `kleros --llms-full` imprime los argumentos completos y los esquemas de salida. `kleros skills add` instala la skill de agente incluida.

<Tip>
Esta es una herramienta distinta del [servidor MCP de la documentación](/es/ai-tools/mcp-server). Ese servidor permite que un asistente busque en esta documentación, mientras que la Kleros CLI lee datos del protocolo en vivo.
</Tip>

## Uso en producción

Los endpoints RPC predeterminados son públicos y gratuitos, y pueden limitar la tasa de solicitudes con tráfico real. Para un uso fiable, apunta las variables de reemplazo `KLEROS_RPC_URL_<CHAIN>` (por ejemplo `KLEROS_RPC_URL_ARBITRUM_ONE`) a un proveedor de confianza. En Ethereum, usa un endpoint con capacidad de archivo, porque resolver políticas antiguas requiere logs históricos.
