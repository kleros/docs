# Resolver V1

<Note>
Dispute Resolver V1 is a standalone application at [resolve.kleros.io](https://resolve.kleros.io) that works with Kleros Court V1. In V2 there is no separate app: dispute creation is built into the [Court V2](/court/overview) interface.
</Note>

Kleros Dispute Resolver V1 (formerly known as "Resolve") is a standalone web application that lets users create arbitrary disputes in Kleros Court V1 without building a custom arbitrable contract. Users define the dispute question, options, and evidence, then submit it directly to Court for resolution.

---

## What It Does

- Lets anyone create a dispute from a web interface
- No smart contract development required
- Used for simple two-party disagreements
- Evidence submission and appeal management through the Resolver UI
- Creates disputes through the V1 [ArbitrableProxy](/developers/arbitrable-apps/arbitrable-proxy) on chains where Court V1 is deployed (see [supported networks](/developers/products/dispute-resolver/overview#supported-networks))

---

## Current Status

Dispute Resolver V1 remains live at [resolve.kleros.io](https://resolve.kleros.io) for Court V1 disputes.

In V2, there is no separate Resolver application. Users create disputes and submit evidence directly within the [Court V2](/court/overview) interface, backed by the V2 `DisputeResolver` contract.
